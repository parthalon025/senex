# senex

Local-LLM code audit tool. Audits a target repository file by file using a thinking-MoE model running in LM Studio, with GitNexus as background graph awareness. Produces per-file Markdown reports, a combined run report, a `findings.json` machine index, and a Claude Code handoff artifact.

**Status:** design phase. See `docs/superpowers/specs/2026-04-26-senex-audit-tool-design.md`.
