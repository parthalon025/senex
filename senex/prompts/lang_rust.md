Rust 2021/2024 edition: `Result<T, E>` and `Option<T>` are the canonical error/absence types; propagate with `?` rather than `match` boilerplate; prefer `match` for exhaustiveness over `if let` at API boundaries. The language's central discipline is ownership and borrow checking. Common defects: `unwrap()` / `expect("...")` on values that are not invariants of the function; ignored `Result` returns (`let _ = ...` without explanation); `clone()` to bypass the borrow checker rather than fix the lifetime; `unsafe` blocks without an inline comment naming the invariant they uphold; missing `Send`/`Sync` bounds where a value crosses a thread; `RefCell` / `Rc` reaching for runtime borrow checks where compile-time would suffice; `into_iter()`/`iter()`/`iter_mut()` confusion; `clippy::correctness` lints suppressed without justification.
